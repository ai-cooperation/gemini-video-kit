# 我們實際怎麼叫 agy 做

這三份是做「用 Google 工具做一支教學影片」時，真的交給 agy 的指令，依序用。換成你的專案時改資料夾名稱與版面數字。

| 檔案 | 做什麼 |
|---|---|
| `01-main-16x9.md` | 網頁簡報＋剪輯，出橫式主片 |
| `02-main-fixes.md` | 看過成片後的修正單 |
| `03-mobile-9x16.md` | 重新編排成手機直式版 |

在 agy 裡貼的那一句：

> 讀 prompts/01-main-16x9.md，照它做完。只能改 work/how-to/ 和 out/，不要寫任何筆記、不要呼叫任何 MCP、不要用 git。

## 做法重點

- **指令寫成檔案**，對話裡只貼一句「讀這份照做」。改指令、重跑、交接都方便。
- **把事實放進 `storyboard.json`**：每句的起訖秒數、畫面文字、出處都先寫好，agy 只負責排版與剪輯，不會自己編數字。
- **規格寫成數字**：尺寸、幀率、字級、小窗座標。「好看一點」沒有用。
- **要求它自己驗收**：抽格拼圖、自己打開看、修到好，再回報沒驗到的。
- **人還是要看**：第一版會露出檔名、進度列亮錯、孤字斷行。看完列成清單再交第二份。
- **權限**：用 auto 模式（自動放行編輯與安全指令），其他逐次看過再按同意；不要選「永久允許」，也不要開全自動放行。

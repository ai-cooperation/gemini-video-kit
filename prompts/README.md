# 我們實際怎麼叫 agy 做

這五份是做「用 Google 工具做一支教學影片」時，真的交給 agy 的指令，原文，依序用。換成你的專案時改資料夾名稱與版面數字。

| 檔案 | 做什麼 |
|---|---|
| `01-main-16x9.md` | 網頁簡報＋剪輯，出橫式主片 |
| `02-main-fixes.md` | 看過成片後的修正單 |
| `03-mobile-9x16.md` | 重新編排成手機直式版 |
| `04-mobile-fixes.md` | 直式版修正單（六頁壓框、切字、圖太小） |
| `05-mobile-fix-l1.md` | 最後一個小修正 |

在 agy 裡貼的那一句：

> 讀 prompts/01-main-16x9.md，照它做完。只能改 work/how-to/ 和 out/，不要寫任何筆記、不要呼叫任何 MCP、不要用 git。

## 做法重點

- **指令寫成檔案**，對話裡只貼一句「讀這份照做」。改指令、重跑、交接都方便。
- **把事實放進 `storyboard.json`**：每句的起訖秒數、畫面文字、出處都先寫好，agy 只負責排版與剪輯，不會自己編數字。
- **規格寫成數字**：尺寸、幀率、字級、小窗座標。「好看一點」沒有用。
- **要求它自己驗收**：抽格拼圖、自己打開看、修到好，再回報沒驗到的。
- **人還是要看**：橫式第一版露出檔名、進度列亮錯、孤字斷行；直式第一版有六頁壓框或切字，agy 自己回報時都說沒問題。看完列成清單再交下一份。
- **你給的數字也會錯**：`04` 給 L1 的圖太大，導致卡片貼到字幕，`05` 才改回來。
- **時間**（2026-11-25，macOS，Gemini 4 Argon high）：橫式第一版約 15 分鐘後撞到額度、等約 1 小時 13 分；修正約 12 分鐘；直式約 22 分鐘，兩次修正各約 12 分鐘。
- **權限**：用 auto 模式（自動放行編輯與安全指令），其他逐次看過再按同意；不要選「永久允許」，也不要開全自動放行。

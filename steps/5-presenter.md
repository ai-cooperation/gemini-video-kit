# 第 5 站 旁白與講師小窗（Colab）

先確認同意（見 RISKS.md 第 1 條）。使用者沒有明說是本人或有書面同意，就只做旁白或跳過。

1. 帶使用者開 [colab-talking-portrait](https://github.com/ai-cooperation/colab-talking-portrait)，照它的 README 做。要選 **L4**，免費 T4 跑不動。
2. 使用者自己準備：方形照片、安靜的錄音、一字不差的逐字稿、自己的 HF_TOKEN。agent 不碰 token。
3. 字稿就是 `storyboard.json` 的旁白，依序一句一行。輸出的 json 有每句起訖秒數，第 6 站要用。
4. 下載影片與 json，**關機**，到「管理工作階段」確認沒有機器在跑。
5. 聽一遍：念錯的字改寫那一句再跑。錄音品質直接影響成品。

小窗放右下，300x300，圓角白框，角落標「AI 生成」。

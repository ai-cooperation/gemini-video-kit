# 用 Google 訂閱做教學影片

把這個 repo 丟給你自己的 agy（Antigravity CLI），它會照著帶你做出一支教學影片：圖片生影像、網頁簡報、講師小窗、旁白與剪輯。

這裡只有做法、範本與檢查清單，**不提供任何伺服器、帳號、點數或模型**。所有生成都用你自己的訂閱、你自己的電腦與你自己的 Colab。

> 作者用 Claude Code（Opus 5.5 high）驗證所有步驟與檢驗成果；還沒測到的項目照實列在文末。

## 開始

1. 裝好並登入 agy，建一個空資料夾，在裡面開啟 agy。
2. 貼上這句：

   > 讀這個 repo 的 AGENTS.md，照它的順序帶我做一支教學影片。先問我主題、觀眾和長度，每一站做完停下來給我看。

3. 先看過 [風險](RISKS.md)。

## 六站

| 站 | 產出 | 用什麼 | 用到的額度 |
|---|---|---|---|
| 1 分鏡 | `storyboard.json` | agy | agy 額度 |
| 2 圖片 | 每個鏡頭的第一格 | agy 生圖 | agy 額度 |
| 3 影片 | 3–10 秒的鏡頭 | Google Flow，以圖片為第一格 | Flow 點數 |
| 4 簡報 | 網頁場景錄成影片 | agy 寫網頁，本機瀏覽器逐格截圖 | 幾乎不用 |
| 5 講師 | 旁白與講師小窗 | Colab（[colab-talking-portrait](https://github.com/ai-cooperation/colab-talking-portrait)） | Colab 運算單元 |
| 6 剪輯 | 成片 | 本機 ffmpeg | 不用 |

不想放真人臉可以跳過第 5 站的小窗，只用旁白。

## 額度怎麼算（2026-11-25 讀官方頁，會變，以官方為準）

**Flow 點數**（[官方說明](https://support.google.com/flow/answer/16526234)）

- **每天 50 點，不管有沒有訂閱都有**。從當天第一次生成起算，隔天補；沒用完不累計。
- **訂閱每月另加**：Plus 200、Pro 1,000、Ultra 10,000 或 25,000。帳單週期開始時更新，沒用完也不累計。
- Omni Flash 1.2，10 秒內：360p 每秒 1 點、720p 每秒 3 點。Plus 以上升到 1080p，10 秒內 0 點。
- 換算：每天 50 點約可試 50 秒的 360p；Pro 的 1,000 點約 166 支 6 秒的 360p。
- 未訂閱者在尖峰時段可能無法生成影片。
- 省點數的做法：先用每天的 50 點生 360p 試動作，確定了再生正式的。

**Colab 運算單元**（[方案頁](https://one.google.com/about/google-ai-plans/)）

- Pro 每月附 200 個，Ultra 每月 1,000 或 2,000 個，表格另列 Plus 50 個。
- 扣法：**每小時費率 × 連線時間**，費率看顯示卡，Colab 畫面上會顯示目前費率。
- 實測 L4 每小時 1.9–2.3 個（2026-11-24、25 兩天就不同）：200 個約可用 L4 85–105 小時；一支 14 秒的小窗實扣 0.44 個，一支 208 秒的旁白加小窗實扣 1.69 個（含安裝與下載模型，約 45 分鐘）。
- 用完會退回免費版規則（Colab FAQ），所以做完一定要關機。

**agy**：[方案頁](https://antigravity.google/docs/plans)只寫額度高低、沒有數字；Pro 是「每五小時更新，直到每週上限」。我們在 Pro 帳號上，同一天生三張圖、再讓 agy（Gemini 4 Argon high）寫完橫式主片的網頁與剪輯，就撞到一次額度，畫面顯示要等 1 小時 13 分（帳號當天也有別的工作在用）。大工作先排在額度剛更新時做。

## 已驗證與未驗證

| 項目 | 狀態 |
|---|---|
| agy 生 16:9 關鍵圖 | 實際跑過（agy 1.5.17，macOS，互動模式）。`-p` 模式在那台機器卡死，互動模式正常；存檔轉檔時會要求同意執行指令 |
| Flow 以圖為第一格、純文字 | 各跑過一支 6 秒 360p（各 6 點，2026-11-25）。360p 下載最高只到 720p（已提升畫質，0 點） |
| agy 寫網頁簡報並剪成影片 | 橫式主片 agy 一次做出 211 秒成片（auto 模式，中間只問了一次權限），人看過後再交修正單；指令在 `prompts/` |
| 網頁場景逐格錄成影片 | macOS 跑過；別台電腦未測 |
| Colab 講師小窗 | L4 跑過 14 秒與 208 秒各一支；HF token 下載、上傳、下載關機三格未測 |
| Windows、Linux | 未測 |
